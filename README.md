# 萬巒鄉預算資料庫

把**屏東縣萬巒鄉公所**的年度總預算書整理成可以查詢、瀏覽和比較的網站與資料檔。

- 網站：<https://show7587.github.io/WanluanBudget/>
- 目前收錄：**114、115、116** 三個年度的總預算案

預算書是掃描的 PDF，沒辦法直接搜尋，也很難跨年度比較。這個專案把它轉成結構化資料，每一筆都標示在預算書的**第幾頁**，方便你對照原書。

## 怎麼使用網站

打開網站後，用上方的選單切換年度和功能：

| 功能 | 可以做什麼 |
|---|---|
| **總覽** | 一眼看到歲入、歲出總額、收支差短，以及歲入來源、歲出政事別、經常門與資本門的比例。點圖上的區塊可以往下查。 |
| **歲出／歲入** | 從大項目一層一層點進去，直到最細的明細。歲入是「款 → 項 → 子目 → 細目」，歲出是「政事別 → 機關 → 工作計畫 → 用途別 → 明細」。每一列都有預算書頁碼。 |
| **比較** | 看相鄰兩個年度（114 與 115、115 與 116）的金額增加或減少多少、百分比是多少。只在其中一年出現的項目會標示「僅 115」之類的字樣。 |
| **搜尋** | 輸入關鍵字，查名稱、說明或編號，可以只看歲入或歲出。 |
| **參考表**（僅 114 年度） | 依原書頁碼瀏覽預算書最後的參考表，例如人事費彙計、公務車輛明細。 |
| **資料備註** | 看預算書本身的錯字、前後不一致等問題的紀錄（見下一節）。 |

小提示：
- 網址會記住你目前看的頁面，可以直接複製分享。
- 手機也可以使用。
- 金額單位一律是**元**。

### 看到 ⓘ 是什麼意思

預算書原件本身偶爾有印刷錯字，或同一個數字在不同頁印得不一樣。這個專案**不會偷偷改掉**，而是照原書保留，並在那一列旁邊加上 **ⓘ**。

點開 ⓘ 可以看到：

- 原書印的是什麼字
- 資料庫目前存的是什麼
- 建議的正確寫法
- 在原書第幾頁、PDF 的第幾頁
- 當時怎麼核對的，以及原書的截圖

舉例：114 與 116 年度第 59 頁把「自治條例」印成了「自治修例」。你搜尋「自治條例」或「自治修例」，都能找到這一筆。

## 資料內容

所有資料都放在 [`data/`](data/) 資料夾，是一般的 CSV 檔，可以直接用 Excel 或其他工具開啟，金額單位都是元。每個年度各有一個資料夾（`data/114/`、`data/115/`、`data/116/`）。

| 檔案 | 內容 |
|---|---|
| `summary.csv` | 各種總表：歲入來源別、歲出政事別、歲出機關別、收支簡明比較等，含本年度、上年度和前年度決算 |
| `revenue_items.csv` | 歲入明細：項目名稱、單位、數量、單價、金額、說明、頁碼 |
| `plans.csv` | 歲出工作計畫：編號、名稱、承辦機關、政事別、總額、頁碼 |
| `expenditure_items.csv` | 歲出明細：每個計畫底下各用途別的說明、金額、經費來源、頁碼 |
| `reference_tables.csv`（僅 114） | 預算書最後的參考表內容 |

另外幾個共用的檔案：

| 檔案 | 內容 |
|---|---|
| `data/memos.csv` | 資料備註表：預算書的錯字、前後不一致、版面限制的紀錄 |
| `data/corrections.csv` | 轉檔時的修正紀錄，每一筆都寫明依據 |
| `data/crosswalk/codes.csv` | 預算書改編號時，新舊編號的對照 |
| `docs/evidence/` | 備註對應的原書截圖 |

## 資料可信嗎

- 預算書自己有加總關係（細目加起來等於子目、計畫加起來等於政事別等），專案每次都會逐一檢查。三個年度目前都通過，結果寫在 [`reports/`](reports/) 資料夾裡。
- 有對不上的地方**不會自動修正**，而是如實列出。
- 少數問題出在原書本身（例如同一個數字在第 1 頁與第 6 頁印得不同），這些保留原樣、記在資料備註裡，等待向公所確認。已知問題整理在 [`docs/TODO.md`](docs/TODO.md)。
- 114 年度有一部分頁面沒有書面原件可以逐一對照，細節在 [`CLAUDE.md`](CLAUDE.md) 的「已知限制」。

## 在自己的電腦上開啟網站

不需要安裝任何套件，只要有 Python 3：

```bash
cd site
python3 -m http.server 8000
```

然後用瀏覽器開啟 <http://127.0.0.1:8000>。想連原書截圖一起看，先在專案根目錄執行一次：

```bash
mkdir -p site/evidence && cp -R docs/evidence/. site/evidence/
```
