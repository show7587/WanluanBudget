### T4-a p1 歲入歲出簡明比較分析表：上年度歲出基準不一致
- p1 上年度歲出合計印 **267,169** 千元，但 p3 收支簡明比較分析表、p9 政事別比較總表、p10 機關別比較總表都是 **271,169** 千元（差 4,000）。
- p1 自己的其他欄位也對不上 267,169：
  - 上年度餘絀 −9,685 = 261,484 − **271,169**
  - 一般政務支出占比 42.10% = 114,168 ÷ **271,169**
- p1「本年度與上年度比較」欄用的上年度歲出是 **267,969**，一般政務支出是 **110,968**：
  - 321,081 − 267,969 = 53,112，增加率 19.82%
  - 119,232 − 110,968 = 8,264，增加率 7.45%
  - 餘絀變動 −1,918 = −8,403 − (261,484 − 267,969)
- 同一張表出現三個上年度歲出數字（267,169、267,969、271,169）。比較欄的基準比其他表少 3,200，全部差在一般政務支出，可能混用了上年度的預算案和法定預算。
- **質詢要問**：上年度歲出正確數字是多少？比較欄的計算基準是什麼？為何一般政務支出差 3,200？

### T4-b p10 歲出機關別預算比較總表：前年度決算合計錯誤
- p10 前年度決算合計印 **322,278** 千元，但本表三個機關加總是 24,201 + 303,559 + 25,500 = **353,260**（差 30,982）。p1 和 p9 的前年度決算也都是 353,260。

- **質詢要問**：前年度決算合計 322,278 是否誤植？正確值是否為 353,260？
